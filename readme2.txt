    const phrases = ['learner - Pentester', 'Cyber Security student', 'still learning'];

[3] <html lang="en"> ไม่เปลี่ยนตามภาษาที่เลือก
---------------------------------------------------------------------
ไฟล์: index.html บรรทัด 2, script.js setLanguage() บรรทัด 9-22
กดสลับเป็นไทยแล้ว document.documentElement.lang ยังเป็น "en" ค้างตลอด
(เช็คจริงผ่าน browser แล้ว) มีผลกับ screen reader/ระบบแปลภาษาของ browser
ที่อ้างอิง lang attribute ควร sync กับ currentLang ทุกครั้งที่ setLanguage() รัน

[4] แถบ nav ไฮไลต์ผิด/ค้างตอนเลื่อนผ่าน section เพลง กับ section โปรเจกต์
---------------------------------------------------------------------
ไฟล์: script.js activeNav() บรรทัด 411-423
ยืนยันด้วย screenshot จริง (เลื่อนแล้ว capture ทุกจุด):
- เลื่อนเข้า #gallery ("what i loop") → nav ยังไฮไลต์ "About" ค้างอยู่
- เลื่อนเข้า #projects ("things i built") → nav ไฮไลต์ "Skills" ทั้งที่ควรไม่มี
  ไฮไลต์ไหนถูกเลย (หรืออย่างน้อยไม่ควรเป็น Skills)
- เลื่อนต่อไปจนเกือบถึง #contact → nav ยังไฮไลต์ "Skills" ค้างอยู่ จนกว่าจะ
  scroll ผ่าน threshold ของ #contact จริงๆถึงจะแก้เป็น Contact

สาเหตุ: activeNav() วนทุก section (sectionEls = ทุก <section id>) แต่ query
`.nav-link[href="#${id}"]` ของ section เพลง/โปรเจกต์จะได้ null (เพราะไม่มี
ลิงก์เมนูให้ 2 section นี้ — ดู [5]) โค้ดมี `if (lnk) { ... }` ครอบไว้ พอ lnk
เป็น null ก็ข้ามทั้ง block เลย ไม่ไป clear active ของลิงก์เก่าออก ทำให้ลิงก์
ที่ active ค้างอยู่จากก่อนหน้านั้นไม่ถูกแก้ไขจนกว่าจะเจอ section ที่มีลิงก์จริง

[6] เพลงเล่นไม่ออก (play() fail) แล้ว UI โกหกว่ากำลังเล่นอยู่
---------------------------------------------------------------------
ไฟล์: script.js toggleMusic() บรรทัด 501-513, simulateProgress() บรรทัด 589-605
    p.then(() => { ... }).catch(() => {
      if (iconPath) iconPath.setAttribute('d', pauseIconD);   // ← เปลี่ยนเป็นไอคอน pause
      setPlaying(audioId, true);                              // ← มาร์คว่า "กำลังเล่น"
      simulateProgress(audioId);                               // ← ปลอม progress bar
    });
ถ้า audio.play() ล้มเหลวไม่ว่าเหตุผลอะไร (autoplay policy บล็อก, โหลดช้า,
ไฟล์เสีย ฯลฯ) โค้ดจะไม่บอก error อะไรเลย กลับไปโชว์ไอคอน pause (เหมือนกำลัง
เล่น) แล้วปลอม progress bar ให้วิ่งจาก simulateProgress() ซึ่ง hardcode เวลา
รวมเป็น "/ 3:30" ทุกเพลง (ทั้งที่เพลงจริงยาว 2:46 / 1:18 / 3:27 คนละความยาว)
สรุป: ถ้า play() fail จะเห็นหน้าจอบอกว่า "กำลังเล่น" progress ขยับ แต่เสียง
เงียบสนิท — ไม่ hang แต่หลอกตาว่าเล่นอยู่ ควรจะโชว์สถานะ error/หยุดจริง
มากกว่า
